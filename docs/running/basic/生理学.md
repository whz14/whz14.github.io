## 人体的能量供给
正如我们中学就学到过的，人体的供能物质有三类，糖类、脂肪和蛋白质。运动中，我们当然不希望蛋白质被消耗 [^protein]，事实上脂肪和糖类就是主要的供能物质。

[^protein]: 完全不消耗蛋白质是不可能的。“在葡萄糖利用受限（如糖原耗竭等）或者长时间运动（超过30分钟）情况下，会增加骨骼肌蛋白质分解提供能量（占比5%～15%）”。高国全，汤其群，生物化学与分子生物学（第10版）[M]人民卫生出版社2024


本小节列举一些或许有用的知识点，其中生化的部分所列的主要用作自己的笔记，如果不感兴趣可以跳过，直接看生化知识带来的[启示](#启示)和[运动相关的重要概念](#运动相关的重要概念)

人体的直接供能物质是ATP，ATP则来自于三个供能系统：
1. 磷酸原系统。肌肉内储备有高能物质肌酸磷酸，可以在肌酸激酶的作用下快速产生少量ATP
2. 无氧氧化系统。底物为葡萄糖和糖原，产生少量（相对有氧氧化）ATP
2. 有氧氧化系统。底物为糖类，乳酸和脂肪，消耗氧气产生大量ATP

<a name="anaerobotic"></a>
糖的无氧氧化可以使1分子葡萄糖能产生2分子ATP，同时2分子乳酸。无氧氧化分2步：
1. 糖酵解。由葡萄糖生成丙酮酸。发生在细胞质基质。
2. 乳酸生成。丙酮酸生成乳酸。发生在细胞质基质。乳酸后续通过不同途径代谢掉。

糖的有氧氧化则可以使1分子葡萄糖产生30或32分子ATP（反应过程有两种机制，导致两种结果），以及水和二氧化碳。糖的有氧氧化分为三步：
1. 糖酵解。同无氧氧化第一步。
2. 生成乙酰CoA。底物为上一步的丙酮酸，产物为乙酰CoA等。发生在线粒体
3. 三羧酸循环+氧化磷酸化。底物为上一步的乙酰CoA等，同时消耗氧气，产生水和二氧化碳，以及大量ATP。

脂肪能产生大量ATP，但脂肪酸碳链长度不同而没有固定对应关系。脂肪的有氧氧化则经历以下步骤
1. 脂肪动员。脂肪在细胞中水解为甘油和脂肪酸，然后运输到其他位置
2. 甘油被转化，进入糖的代谢途径。主要发生在肝。
3. 脂肪酸进入细胞，经过$$\beta$$-氧化，生成乙酰CoA等，然后进入三羧酸循环+氧化磷酸化，和糖的有氧氧化一样。

糖原如何使用则依位置不同而不同
1. 肝糖原水解，产生葡萄糖，进入血液，运输到需要的位置再氧化。
2. 肌糖原直接进入糖酵解，随后接有氧氧化或无氧氧化的途径，产生能量。

<a name="lactate_metabolism"></a>
上面提到糖无氧氧化产生乳酸，乳酸的代谢途径则有
- 运送至肝脏重新变成葡萄糖（非糖物质转化为糖的过程，称为糖异生）[^cori_cycle]。
- 运送至心脏，心脏利用乳酸产生能量（心脏可以用多种物质供能）
- 另外，运动强度不大、并不缺氧的肌肉也可以通过有氧氧化代谢乳酸。

[^cori_cycle]: 肌肉产生乳酸运到肝脏，肝脏将乳酸变成葡萄糖再运到肌肉，肌肉再产生乳酸再运到肝脏，这个过程称为乳酸循环或Cori循环


### 启示
- 注意三种能量来源（糖脂肪蛋白质），三种供能系统（磷酸原、无氧、有氧），以及糖的有氧氧化的三步**没有对应关系**。
- 由于每个人运动效率的不同，不同人的摄氧量不能比较
- 消耗能源物质&氧气，最终产生能量，这件事发生在需要用能量的细胞。所以使用不同肌肉的不同运动项目，测得的摄氧量也不能比较！用划船来测量摄氧量，练划船滑雪的运动员，一定比跑步运动员更高，但这不能说明二者的腿的强弱。
- 脂肪只能有氧氧化，而糖类可以有氧氧化也可以无氧氧化。
- 糖原相比脂肪能更快速地提供能量，毕竟脂肪供能需要有动员、运输过程，后续出路也更单一。
- 考虑到上两条，我们可以得出结论：脂肪和糖原供能的比例与运动强度有关。时间长、强度低时，身体可以用脂肪供能；当强度较大来不及让脂肪动员时，使用糖原就成了唯一的选择；而强度继续增大，线粒体相关的有氧能力成为瓶颈，就只能仰仗不需要线粒体的无氧呼吸供能了——结果就是产生乳酸，乳酸堆积会破坏体内稳态，要么在稳态被破坏前完赛，要么就只能降速乃至崩掉。而强度、时间和供能物质比例如下图所示

## 运动相关的重要概念

运动时，我们经常会使用各种概念，比如衡量运动能力的**最大摄氧量**，应用于训练的**乳酸阈**，如果去做运动心肺实验，还会有**无氧阈**，又会听说**临界速度**等。这些概念非常常用，但它们的定义是什么？生理学意义是什么？对应关系又如何？这些概念我们虽然经常使用，但理解并不够深入，难以回答这些问题。本文将会尽最大能力做出总结，或许是中文互联网上的对这些概念做出辨析的第一篇文章。

本小节将会首先介绍最简单有效的[最大摄氧量](#最大摄氧量)概念，随后简要地介绍对跑者而言同样有效，但稍微复杂的[乳酸阈值](#乳酸阈)概念，接下来为了理解乳酸阈，会较为深入地介绍[运动过程中血液中的乳酸如何变化](#心肺运动试验中血乳酸的变化)，以及基于这样变化产生的[第一乳酸阈](#第一乳酸阈)和[第二乳酸阈](#第二乳酸阈)概念。第一乳酸阈在训练中鲜有提及（对用时1小时以下的场地比赛和对精英选手的半马影响较小，只会对马拉松等2小时以上的运动影响），它主要在医院的运动心肺实验中会用到，而第二乳酸阈就是跑者们常说的乳酸阈值。最后则会介绍比较新的[临界速度](#临界速度)概念。

### 最大摄氧量
需要氧气参与的糖类和脂肪的有氧氧化是长跑的主要能量来源，因此可以用**最大摄氧量, $$VO_{2}Max$$**来衡量运动能力。

有氧运动时，我们消耗氧气产生能量，产生的能量与氧气正相关（注意由于运动强度不同，供能物质的不同，二者不是正比），所以摄氧量$$VO_2$$会随着运动强度变化而变化，摄氧量达到最大值时表明运动员本人到达了有氧运动的极限。摄氧量（最大摄氧量）的单位为 L/min/kg。

最大摄氧量对应着一定的运动强度，人们通常能在这个强度下坚持12min左右

### 乳酸阈
乳酸阈的概念是一个大坑。

跑者们说的“乳酸阈”往往是指这样一个东西：乳酸阈是一个**特定的运动强度**，在这个强度阈值之下，乳酸产生的速度小于能代谢乳酸的最大速度，而在这个强度阈值以上，身体将会无法处理多出来的乳酸，使得运动不能维持下去。这个定义非常有可执行性，我们制定的运动计划，往往是要按照某个强度运动，比如配速或等强配速或功率，而不是其他的参数。

在丹尼尔斯体系中，作者并没有给出乳酸阈值的具体定义，而是给出了一张表格，跑者们可以通过查表得到乳酸阈；作者还将其定义为可以全力跑40分钟到1小时的速度，跑者们也就可以通过自己10k的成绩来估算乳酸阈值。

与此同时，有人认为乳酸阈是一个生理概念，指**特定的血乳酸浓度**。因为人类静息状态下的血乳酸浓度为1mmol/L左右，上升到较高的浓度就意味着稳态被破坏，所以就用特定的值，比如4mmol/L来当做乳酸阈值。然而特定乳酸浓度这个概念和跑者们需要的特定运动强度虽然有联系，但不等价——我们在[启示](生理学.html#启示)一小节中提到，有氧氧化供能和葡萄糖的无氧氧化供能并非非此即彼，而是随着强度的上升（即运动时间的缩短），无氧供能的比例提高，也就是产生乳酸的速率会提高。**运动强度与乳酸的产生速度对应，而非乳酸浓度；乳酸产生速度与血乳酸浓度是微分与积分的关系。** 只要运动强度大于前面提到的特定阈值，血液中乳酸一定能积累到任意足够高的浓度，直到身体顶不住，只能停跑。举个例子，假设我们能实时监测乳酸浓度，而一名被忽悠过来不明真相的跑者来做莫名其妙的跑步测试，跑步机被设置得非常快，远超我们常说的“乳酸阈”配速，但血乳酸上升需要时间，当我们测到4mmol/L的时候，实际的运动强度早就超过运动的稳态了。

既然血乳酸浓度并不是好用的乳酸阈定义，那么为什么有人在用呢？因为这个概念在特定的测试条件下成立，乳酸浓度需要绑定的这个测试条件就是**心肺运动实验**，cardiopulmonary exercise test，缩写CPET。

### 心肺运动试验中血乳酸的变化

心肺运动实验(CPET)是医疗行为中更常用的一种方法，运动人群借用这个实验方法用以评估自己的能力。CPET常用的试验方法是阶梯渐进式运动测试(graded incremental exercise tests, GXT或IET)，阶梯式地增加运动强度，这样。与此同时监测生理指标，诸如通气量（单位时间的呼吸气体体积）、潮气量（单次呼吸的气体体积）、吸入呼出的二氧化碳含量，吸入呼出的氧气含量，医疗目的的CPET还会增加血压和心电的测试。

> 实际的CPET中很少直接测血乳酸，因为扎针太麻烦了。人们通常用其他指标来估算血乳酸变化。

心肺运动试验中，运动强度并非均匀线性增加，而是阶梯式增加，上到一个阶梯后的固定强度使得身体能够达到该强度对应的稳态（如果真是个稳态的话）[^bla_calc]，从而方便测量。而后再增加到下一个阶梯。

[^bla_calc]: 为了说明几分钟甚至几十秒内，身体就能达到这个速度新的稳态，不妨估算一下血乳酸上升所带来的能量。人体体重7~8%为血液，血液密度1.04，[上文](生理学.html#anaerobotic)提到1分子乳酸对应1分子ATP，ATP水解提供的热量为30.4kJ/mol=7.3kcal/mol。因此对于一个体重为W的人，血乳酸从静息状态的1mmol/L上升到4mmol/L，血液中的多出来的乳酸对应的能量为$$8\% * W /1.04 * 3 *10^{-3} *7.3=1.7*10^{-3}kcal*W$$ 跑步耗能估算公式则是$$能量/kcal = 体重/kg * 距离/km*1.036$$，所以不难估算，血乳酸上升3mmol/L，对应的能量只能使人跑1m左右！虽然这个估算有大量的近似，最多只有数量级可信，但至少意味着从能量角度看，血乳酸浓度上升本身提供的能量，只能使人多跑很短的距离，所以跑一分钟或几十秒的时间，身体大概率能达到新的稳态。

介绍完了心肺运动实验，正式开始乳酸阈的变化过程。**以下内容参考了[这篇文章](https://runningwritings.com/2024/01/critical-speed-guide-for-runners.html)**

人们在静息状态下，血乳酸浓度在1mmol/L左右。当我们开始以一个较低强度运动时，血乳酸浓度并不会上升，因为糖类或脂肪的有氧氧化，就完全可以提供运动所需的能量，不会产生乳酸。

当运动强度上升，血乳酸浓度会迎来第一个提升，然而血乳酸浓度不会无限上升，而是经过一段时间后到达一个稳定的值而非无限涨下去，这时身体仍然处于一个稳态，而这个血乳酸第一次提升的运动强度称为**第一乳酸阈**。

运动强度继续上升到下一个阶梯，血乳酸仍然会上升，然后保持在一个稳定的浓度，这时的身体状态与刚刚超过第一乳酸阈的状态并无本质区别，直到再下一个强度阶梯。

随着运动强度的继续上升，终于迎来了一个临界点，超过这个临界点后哪怕强度不增加，血乳酸依然会缓缓上升，这样的强度维持了几十分钟后，血乳酸浓度达到了一个较高的值，测试的跑者终于没法再坚持下去，走下了跑步机。而这个临界点被称作**第二乳酸阈**，恰好处在这个临界点时，人体产生乳酸的速率与代谢乳酸的最大速率相等，这个状态叫做**最大乳酸稳态，Maximum lactate steady state, MLSS**[^MLSS_test]。

<a name="Aero_Th"></a>
![Aero_Th](/imgs/running/basic/lactate-workload_plot.png)

上图[^LT_stories]中的Aerobic threshold为本文中提到的第一乳酸阈，anaerobic threshold为本文中的第二乳酸阈。

[^MLSS_test]: 虽然笔者在此文中会混用MLSS和第二乳酸阈，但它俩是相近但并不完全相同的概念。第二乳酸阈通过阶梯渐进式运动而后进行数据处理测得，而MLSS的测试金标准则是让受试者在某个强度下运动30分钟，同时监测血乳酸浓度。如果血乳酸浓度不上升，那就在几天后再在更大的强度下测试。这样测试MLSS显而易见成本更高。

需要提一下的是，第二乳酸阈对应的强度并非最大摄氧量，如果我们同时监测摄氧量，在运动强度超过第二乳酸阈后摄氧量依然能继续增加，只不过乳酸上升速度会更快，测试者会更早地到达极限停止测试。


### 第一乳酸阈

上文中将第一乳酸阈定义为使血乳酸第一次上升的运动强度，这只是定义之一，笔者之所以选择使用这个定义，是因为它的优势在于对于跑者们有着更强的可执行性。

第一乳酸阈的运动强度并不高，只要比轻松跑[^HR_zone]更快就能超过第一乳酸阈。笔者在2023年秋天的一次CPET实验中，自行处理数据测出来第一乳酸阈为大约13km/h，即大约4'36"/km的配速，而笔者当时的全马成绩大约为2h45'，4'36对这个水平的跑者大概是轻松跑上限的程度[^vslope]。


[^HR_zone]: 跑者们的轻松跑是一种体感，运动手表里的区间则用心率区间划分。体感、心率区间和乳酸阈事实上也没有严格的对应关系。

[^vslope]: 这一数据使用v-slope法自行处理数据获得，速度精度1km/h。v-slope法基于如下原理：未产生乳酸的状态下二氧化碳在血液中溶解度高，吸入氧气-呼出二氧化碳呈线性关系。当血乳酸上升时，血液PH降低，二氧化碳溶解度下降，此时摄入氧气-呼出二氧化碳的曲线将出现一个拐点，拐点后被认为是斜率不同的线性关系，这个拐点对应的强度即为第一乳酸阈。数据处理代码和数据文件见[这里](https://github.com/whz14/whz14.github.io/)，处理结果如图 ![V-slope-lt1](/imgs/running/basic/physiology-AT.jpg)。

### 第二乳酸阈

上文中，笔者认为第二乳酸阈与最大乳酸稳态MLSS称为同一种东西，这是一种定义方法，但并非公认。事实上，第二乳酸阈值有很多定义，包括固定血乳酸浓度(4mmol/L)、基于其它概念然后再加减固定血乳酸浓度[^LT2_definition2]、甚至对血乳酸曲线做几何上的处理[^LT2_definition3]等。这些定义方法方便实验室测定，而笔者倾向于使用的最大乳酸稳态定义更便于理解。

最大乳酸稳态时，运动的肌肉产生乳酸的速率等于身体能消耗乳酸的速率，经过训练的耐力运动员们能够在这个状态下坚持1小时左右的时间，这正是精英选手的半马或大众高手们跑16公里的用时。大众高手半马也会在80分钟以内，因此半马比赛配速仅仅比MLSS慢一点。

目前大家的实践中，锻炼MLSS能力的最佳方法是在MLSS强度附近训练，注意到MLSS并不是一个很难坚持的强度，所以训练中很容易跑到比MLSS更快的速度，因此在一堂阈值训练课中，如何压速度是一项很需要注意的点。



### VDOT

本小节只简要介绍VDOT，VDOT是丹尼尔斯训练体系的核心，详细介绍请参阅《丹尼尔斯经典跑步训练法》一书或[丹尼尔斯体系](/running/daniels/index.html)一章。

VDOT是丹尼尔斯提出的一个模型。

丹尼尔斯是一名跑步教练，他在指导队员过程中发现，不同距离的比赛成绩之间可以换算，比如用1500估计3000，用3000估计5000……用半马估计全马，因此他抽象出了VDOT这个概念，VDOT越高，在中长跑的各种距离上的能力也就越强。

丹尼尔斯也通过实验（经验）建立了VDOT和各种比赛距离的成绩以及训练类型的映射关系，通过某距离的比赛成绩，查表得知VDOT，从而一方面预测其它距离的比赛的成绩，另一方面得知训练类型对应多少配速。“训练类型”指他的轻松跑E(easy)，马拉松配速跑M(marathon)，乳酸阈值跑T(threshold)，间歇跑I(interval)和重复跑R(repeation)。

> **注意，丹尼尔斯会管他的阈值跑叫“节奏跑”，他口中的节奏跑，其速度也是在乳酸阈值速度；而其他体系中的“节奏跑”往往取tempo一词的本意，即稳定在任意速度的跑步。而间歇跑I也特指速度在最大摄氧量配速的跑步，虽然在他的训练体系中，乳酸阈值跑T和重复跑R也是跑动-休息的形式，但它们不叫“间歇跑”。**

VDOT的量纲和最大摄氧量一样，笔者习惯将VDOT理解为最大摄氧量VO2max乘以跑步经济性的系数得到的值。

### 临界速度

本小节写作时参考了[这篇文章](https://runningwritings.com/2024/01/critical-speed-guide-for-runners.html)。本小节只简单介绍临界速度的概念，其详细原理和应用方法，请参考[临界速度](/running/cv/index.html)一章

临界速度是一个描述跑步的数学模型。这个模型认为，对于30分钟以下的比赛，比赛成绩和距离的关系服从以下双曲线函数

$$
t_{lim}=\frac{D'}{s-CS}
$$

其中$$s$$为比赛速度，$$t_{lim}$$为比赛时间，$$D', CS$$为参数。$$D'$$的含义为能量储备，而$$CS$$即为我们要考察的重要的“临界速度”，critical speed[^CS_name]。

[^CS_name]: 临界速度英文名有critical speed和critical velocity两个，这两个名字唯一区别就是speed为标量而velocity为矢量，跑步时我们并不关心标量或矢量，所以cs和cv经常混用。

临界速度模型相对VDOT有以下优势

- 临界速度模型有两个参数，相比只有一个参数的VDOT，预测能力的上限更高。
- 临界速度模型用20分钟以下的比赛成绩拟合参数，预测30分钟以下的比赛效果更好。
- 临界速度模型认为重要的训练类型只有两类，临界速度以上和临界速度以下，所以制定训练计划时可以更加宽松。
- 临界速度模型还认为，临界速度是更能反映运动时生理学本质的模型，所以针对临界速度的训练更加有的放矢，提升运动表现事半功倍。
