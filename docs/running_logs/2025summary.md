# 2025年终总结
2025年过去了，我的心情很复杂。先是重庆马拉松远没有达到预期的成绩，和过往的付出完全不相称。然后是尝试重新开始训练，场地、马拉松、越野、铁三，不以成绩为目的，只是为了借机旅游游山玩水，然而伤病接踵而至。

本以为“最差也就是停跑两周，然后怎么都好了”，可最终折腾了5个月之久，直到现在也没彻底痊愈，而仅有的慰藉是我在尝试康复的过程中似乎变得更加成熟，被迫思考如何看待成绩，如何看待伤病，如何提升成绩，如何解决伤病……

本篇流水账会草草讲讲经历的几场比赛，然后着重讲讲我是如何被伤病困扰，然后山重水复的——说山重水复，就是想暗示我似乎见到了柳暗花明。

## 2025的比赛们

### 新年半马
2025年1月1号，我在奥森跑了一场半马。
这场半马本身没什么可说的，用最近常见的话讲，可以叫“有经济上行期的美”。那时仍然斗志昂扬，仍然充满希望，携北马PB之威，觉得当时训练状态也不错，想要以赛代练拿个好成绩，也在畅想着两个月后的重庆马拉松。最终我在一场有战争迷雾的比赛中惊喜地获得了第三。我更自信了。

![2025新年半马pyq](/imgs/running_logs/2025/01_NYhalf.png)

### 重庆马拉松
直到重庆马拉松比赛进行到12公里，我才认清现实。

把时间倒回到1月，我仍然进行着训练，手表显示的负荷正常，自我的感觉良好，右脚踝有些疼问题不大，嗓子有些疼大概是约饭时聊天聊得过于激动说得太多，测了核酸只是感冒而已。

当我踏上重庆，第一次来到祖国的西南，贪婪地想要趁机更多地了解这座神奇的山城。住的酒店虽然有点爬升，但对我这种已经充分休息的人来说，完全不是问题。

我对火锅本来就不感冒，几天内一直在吃小面，而事实证明重庆小面很对我胃口，以补碳为目的，我在kuku狂炫。

直到比赛的时候。

12公里处，本以为不会再出现的左脚脚趾失去知觉又出现了，且比过去更早更严重，也更容易触发——我当时的配速“只”有345，是一个理论上应该还很轻松的配速。然后就是降速，思考能保住什么成绩，然后开始担心会不会脚趾缺血坏死，会不会已经有血栓形成，然后血栓脱落成为chubbyemu素材，WH is a 29-year-old man, presenting to the emergency room...... 随后我逐渐认清了现实，经过2小时的思考人生，我的心和脚趾一样麻木，过线，机械地感谢志愿者，挪动着领包，尴尬地拿小金人，在周围的喜悦中格格不入。

现在（2026.01）回想，那个24630的成绩是现在的我难以企及的成绩，但考虑到当时的巨大付出和巨大期待，我仍然能够共情那时的自己，不会说他“卖菜”。

就这样，我最寄予厚望的比赛结束了，结束得很尴尬

![2025重庆马拉松](/imgs/running_logs/2025/03_CQMarathon.png)

但这只是黄昏。

后面还有寒冷的黑夜呢。

### 夜幕降临

好吧，这个小标题是很中二，但我就是想到倒苦水，把之后跑得很不满意的比赛报菜名一带而过。

3月下旬是很久没跑过的长距离越野，75km的浙江温岭。已经跑过百公里的我本来应该不会畏惧75km的比赛，但接连不断的石板路还是让膝盖出了问题，最后只能在平地缓慢挪动。好消息是一起跑75km的昌老师和yrm成绩都不错，赛前也见到了很久不见的同学们。所以作为旅游还挺满意的，但作为比赛很难受。

4月中旬的北半马居然掉签了，也是我人生第一次掉上马之外的签，于是蹭了二队的名额去跑了上半马。
而本来早一周的校马因为大风改期和上半马撞车，于是鸽了校马，错失仅有的机会。上半马偶遇了大正，最后终于A区出发，120完赛，直通上马本来就没指望，也算在预料之内。回京路上来了一次极限冲刺，作为旅游还挺有意思的，但作为比赛很遗憾。

5月在奥森的K马和队友们组了团体赛，抱大腿混到了团体冠军。作为比赛结果很好，但作为团队一员还是有些羞愧。

6月中旬赤城100，想要跑个没有这么多石板路的越野证明一下自己，发枪前偶遇了橙飞老师，但突如其来的大雨，一脚带起一斤泥的路况，以及离奇疼痛的左腿让我做出了退赛的决定，越野生涯似乎圆满了。从人生经验考虑退赛很正确退赛经历也很重要，但作为比赛还是有些不满。

休息几周后，感觉身体没什么异样，工作生活似乎一切回到了正轨，天晴了雨停了，可以开始准备下个赛季了吧，2025年秋，要不再信一次？

但凌晨以后夜晚才会真的变得死寂。

夜晚的死寂将会教训每一个头铁的人。

## 2025的伤病与转机
### 长夜漫漫
变化似乎发生在7月的那几次短间歇之后。周期伊始，几次短间歇（repitition）是很好的提高跑步经济性、无氧能力等等方面的机会，而我跑短间歇后从来都会小腿疼大腿疼，所以一开始没有在意。
直到短间歇的阶段结束，开始乳酸阈+最大摄氧量的体感最困难也是提升最大的阶段时，我才注意到不对劲。

**左大腿后侧，怎么一直都在疼？**

休息能稍有缓解，但不想耽误训练，于是继续。

8月中旬有呼和浩特半马，8月底有哈尔滨马拉松，所以还得继续。

周期结末尾的目标是北马，所以当然要继续。

“现在疼就疼，反正我有最后一招，大不了像之前每一次那样，趁某次感冒躺平休息两周”。曾经确实有过肌肉疼痛，但每一次只要趁着感冒彻底躺平几天，完全停练两周就能完全痊愈，这是我亘古不变，从没观测到反例的经验。就这样，我继续着训练，如果跑步实在难受，就用骑车代替。

*但事情好像没有在变好，于是我慌了。*

去了北医三院运动医学，左髋关节有点小问题，但在外科视角里不用做手术的都不算问题……

去了某博康复，title看起来很牛逼的康复师说我没什么大问题，来这里花钱上课就好……

去了西苑医院康复科，冲击波、手法按摩之后能有几天好转，但到下次走进康复大厅时，一切如旧……

在此期间，我在呼和浩特半马凑合地跑出了124，然后打着肌贴哈尔滨马拉松跑崩跑出6年以来最差成绩308，接着在家门口的阪泉公园半马跑出了凑合的123，成绩并没有差到哪去，疼痛也没恶化到哪去。然后在十一期间恰好感冒，然后完全躺平一个假期，可该疼还是疼，也没好转到哪去。

相较于一瞬间的天塌地陷，时刻不停地钝刀子割肉更多地磨人心性，我不知道什么时候会神奇地康复，也不知道哦什么时候会崩塌，就这样在迷茫中不知道未来与末日哪个先来，然后作为没头苍蝇乱撞一气……

直到有一天，我把之前总结给人类医生康复师看的病程记录输入到了llm对话框里。

### 黎明将至
为了这碟醋，我包了一案板饺子，蒸了两屉包子，又下了一锅面条。我写了这么长的流水账，就是为了说一件事：

**我推荐所有有运动伤病的朋友，用LLM分析一下自己的问题**

我曾经为人类医生和康复师总结了病程，包括
- 我的基础情况（男，跑龄7年，典型月跑量300km）
- 伤病开始时间（半年前，或许是短间歇冲刺诱发）
- 疼痛情况（左腿股二头肌高张力、疼痛）
- 什么情况下加剧（短间歇、久坐、坐马桶压到股二头肌）
- 什么情况下缓解（冲击波治疗、拉伸）
- 已做的医学检查（没有腰间盘突出问题，有轻度髋关节盂唇损伤和髋关节装机综合征）
- 其它问题（左腿股外侧肌一根持续很久的硬条，侧躺时从轻度屈髋到伸髋时会有弹响，左脚趾在中高强度运动时会出现麻木的情况）

LLM在康复领域有着各种优势
- 它有人类医生难以比拟的优势，我能随时随地地找到它，花上几个小时去分析问题
- 它相比医疗场景能回避自己的劣势，康复不依赖影像学或检验科的实验室检查，只需要我配合着做几个动作
- 它还有多少有点难绷的好处，讨好型人格的它能提供各种情绪价值，鼓励我坚持跑下去

而2025年的模型已经足够聪明，具备定位问题的能力。

经过了一系列的检验动作和左右互搏，我终于定位到了一个似乎能说得通的问题：左髋发力模式不正确导致的左髋稳定性不足，从而导致代偿，从而导致股二头肌过度发力导致了疼痛。同样地，发力不正确导致了力线不正，从而导致了脚趾的问题。

具体说来，是臀肌的问题。

解决方法也就很直接：让我的小脑想起我还有屁股可以用，而不是单纯地用腿。臀肌用起来应该是什么样也很明确：用不疼的腿当ground truth就可以了。

于是在它给出我建议的第一天，我从工位上起身，手放在屁股上走了几步，惊讶地发现左臀肌在走路时相对右臀没有用力，而有意识地用力后，我惊喜地发现左股二头肌的疼痛减轻了。
这是半年以来，最明显的一次减轻，优于拉伸，仅次于创伤性的冲击波。

随后是通过各种手段让臀肌一点点地上线，也是在此期间，我了解到了一个很重要的概念：**“激活”**

在训练前做的激活不同于热身，就像在训练后做的放松不等同于拉伸一样。激活能够让小脑意识到自己还有哪块肌肉可以用，哪块肌肉应该使用。

激活本身会让被激活的部位有一点累，只能用上80%的力量，但如果不做激活，这个部位可能完全用不上，也就是只能用到0%的力量。如果这里用不上，那就很可能导致代偿等等现象，然后导致问题。

从那开始，我在遇到伤病问题时，第一反应永远是打开电脑问问模型，谈及伤病和康复话题时，我也会给大家推荐各路LLM。

直到今天，我的左股二头肌确实还会时不时地疼一下，但相比之前的频率已经大幅下降，而更重要的是，我发现了臀大肌经常不用力的问题，解决了持续至少5年的弹响，缓解了2年的股外侧肌紧张，人生第一次在跑步时用上了臀肌——直到“学会”跑步的20多年后，我才知道用上了臀肌是什么感觉，而第一次感受到时我还不敢相信，直到向更擅长中跑的队友们确认了一下，才真正相信。

没有什么一劳永逸的方法。
