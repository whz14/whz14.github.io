# 2025重马赛记

## 摘要

在赛前很早就做好了决定，重庆马拉松是可以预料的未来内最后一场认真备赛的全马，我也投入了巨大的心血——最后一舞与巨大心血互为因果。备赛期的各个方面，我自认为做的非常不错，很多之前没机会尝试的细节优化也能做到。

然而重马的结果令人只有苦涩，2:46:29的成绩比期待的2:38:59差得很远。想到这样尴尬的谢幕，也就只能哀叹，重庆毕竟是两江交汇，一面用眼看水长东，一面用心感受人生长恨。

回京两天后打开电脑，纠结之后还是开始写这篇总结。虽然从功利角度看，当我重新开始跑步时，这样一篇记录理论上巅峰期如何翻车的文章不会有什么用，但从心理角度思考，我还是想梳理一下备赛和比赛，反思这次是如何翻车的，哪怕只是矫情个几千字，倒一倒心中的垃圾，也是给自己一个交代。

## 备赛：课表

重马的备赛开始于赛前8周。我回顾了一下之前在ARE期间的训练，大量的最大摄氧量间歇很好地提高了我的上限，但单次场地强度课由于时间原因只能跑不到20km，这对于马拉松训练来说是稍显欠缺的。另一方面，ARE课表中从来没有乳酸阈值训练，这也是可能让上限无法发挥的一个因素。而丹尼尔斯课表能很好地解决这一问题——

![丹尼尔斯18周课表p1](/imgs/running_logs/2025/cq_mrth_daniels_18weekp1.png)
![丹尼尔斯18周课表p2](/imgs/running_logs/2025/cq_mrth_daniels_18weekp1.png)

每周两堂大课，每堂24km以上，乳酸阈训练比最大摄氧量训练多；每周4天再加一个小时的轻松跑，这样总的周跑量在110~120km左右，根据上次北马的经验，这个总量不会让我过于疲劳。

我还花了两个小时，设置了高驰的训练日程，这样一是方便这轮训练，二是万一能复用呢。

![高驰8周课表](/imgs/running_logs/2025/coros_schedule.png)
